 Картки класів
1.
1) клас Bike | Конструктор (plate) | Метод fee_per_min() повертає ціну за хвилину. Метод kind() повертає тип велосипеда
2) підклас ElectricBike(Bike) | Знає plate з батьківського класу, + атрибут battery | Метод fee_per_min() повертає ціну за хвилину. Метод kind() повертає тип велосипеда. Метод is_ready повертає True, якщо велосипед заряджений хоча б на 20%. Метод battery_percent() повертає який заряд батареї. Метод ride(minutes) забирає заряд батареї за кожну хвилину. Метод recharge() перезаряджає батарею до 100%
2.
1) клас Station. Метод add_bike додає велосипед на станцію. Метод take_bike забирає велосипед зі станції. Метод bikes_count повертає кількість велосипедів які є на станції.

3. Клас Customer:
   Додає клієнта(його ім'я та баланс)
   Метод ride повертає вартість поїздки, оновлює баланс користувача. Метод ride повертає вартість поїздки, оновлює баланс користувача. Також в цьому тетоді байк забирається зі станції
   Mетод add_money(amount) дозволяє поповнити рахунок,повертає оновлений рахунок)
   
4 Клас Rental_Network:
	1 Створюється порожній список станції та лічильник заробітку.
	2 Метод add_station() додає станції до мережі
	3 Метод register_payment(amount) збільшує загальний заробіток на суму поїздки
	4 Метод bikes_per_station() повертає словник: назва станції -> кількість велосипедів на ній
	5 Метод total_revenue() повертає загальний заробіток мережі.
